# Results — synthetic demo run

> These numbers come from the **synthetic** EEG generated by `python -m eegct synth`. They show that
> the full pipeline works end to end. They are **not** clinical or scientific results. Re-run
> with `configs/real_data.yaml` on the real datasets and put *those* numbers in your report.

Setup: 95 recordings from 5 simulated "datasets" (TUH-, CHB-MIT-, ds004504-, ds002778- and MODMA-style
EDFs at 250/256/500/512/250 Hz, each with its own channel naming), harmonized to an 18-channel bipolar
montage at 128 Hz and cut into 4 s windows (9,501 windows). Split is **subject-wise**: 57 train / 13 val /
13 test subjects. CPU training takes ≈ 47 s/epoch. Early stopping picked epoch 15.

## Multi-disease task (5 classes)

| Metric | Value |
|---|---|
| Window accuracy | 0.855 |
| Window balanced accuracy | 0.905 |
| Window macro-F1 | 0.883 |
| ROC-AUC (one-vs-rest) | 0.956 |
| **Recording-level accuracy** (15 test recordings) | **0.933** |

| Class | Precision | Recall | F1 | Test windows |
|---|---|---|---|---|
| Healthy | 0.72 | 0.84 | 0.77 | 445 |
| Epilepsy | 0.98 | 0.76 | 0.85 | 598 |
| Alzheimer | 0.92 | 1.00 | 0.96 | 178 |
| Parkinson | 0.75 | 0.92 | 0.83 | 178 |
| Depression | 1.00 | 1.00 | 1.00 | 178 |

Nearly all Epilepsy errors are **interictal** windows (between seizures) predicted as Healthy. A check on
the test patients' full recordings found 100 % of ictal windows (283/283) classified as Epilepsy, against
49 % of interictal windows. This is expected, because interictal EEG often looks normal. Recording-level
voting fixes most of these errors.

Grad-CAM channel importance (top 5 per class, averaged over correctly classified test windows):

| Class | Most important bipolar channels |
|---|---|
| Healthy | CZ-PZ, C3-P3, C4-P4, P8-O2, P7-O1 |
| Epilepsy | FP2-F4, F7-T7, FP2-F8, FP1-F3, F8-T8 |
| Alzheimer | P3-O1, P4-O2, CZ-PZ, C4-P4, C3-P3 |
| Parkinson | P7-O1, P8-O2, C4-P4, C3-P3, CZ-PZ |
| Depression | P4-O2, P3-O1, FP1-F3, F7-T7, FZ-CZ |

Healthy, Alzheimer and Parkinson decisions rely on the posterior (alpha-rhythm) derivations. Epilepsy
relies on the fronto-temporal channels where the simulated epileptiform focus sits. Depression uses
frontal channels (the simulated frontal-alpha-asymmetry marker) together with posterior alpha.
